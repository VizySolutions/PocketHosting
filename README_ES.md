# PocketHosting

**Idioma:** 🇧🇷 [Português](README.md) | 🇺🇸 [English](README_EN.md) | 🇪🇸 **Español**

---

**PocketHosting** es una aplicación para Android desarrollada por **Vizy Solutions** para crear, administrar y ejecutar servidores **Altay** directamente desde un dispositivo móvil.

El objetivo de la aplicación es permitir que desarrolladores, propietarios de servidores y usuarios avanzados puedan probar plugins, mundos y configuraciones de Altay sin necesidad de contratar un alojamiento externo ni mantener una computadora encendida todo el tiempo.

---

## Sobre la aplicación

PocketHosting convierte un dispositivo Android en un entorno de pruebas para servidores de Minecraft Bedrock utilizando Altay.

Con la aplicación, el usuario puede descargar, iniciar, detener, reiniciar y administrar un servidor Altay directamente desde el propio dispositivo mediante una interfaz simple y práctica.

La aplicación fue pensada principalmente para:

- Desarrolladores de plugins para Altay;
- Propietarios de servidores Minecraft Bedrock;
- Usuarios que quieren probar configuraciones localmente;
- Personas que no disponen de alojamiento de pago;
- Proyectos de estudio, desarrollo y pruebas.

---

## Funciones principales

- Crear y ejecutar un servidor Altay en Android;
- Descargar la versión más reciente de Altay desde los releases oficiales;
- Iniciar, detener y reiniciar el servidor;
- Consola en tiempo real;
- Campo para enviar comandos directamente al servidor;
- Visualización del estado del servidor;
- Visualización de la IP local y el puerto;
- Visualización de jugadores en línea;
- Visualización de la versión de Altay;
- Administrador de archivos integrado;
- Edición de archivos del servidor;
- Envío de archivos al servidor;
- Sistema de idiomas.

---

## ¿Para qué sirve?

PocketHosting facilita la creación y administración de servidores Altay en dispositivos Android.

Puede utilizarse para probar plugins, configurar mundos, editar archivos del servidor, ejecutar comandos desde la consola y comprobar el funcionamiento del servidor antes de trasladar el proyecto a un alojamiento profesional.

También puede utilizarse como una solución sencilla para quienes desean ejecutar un servidor local dentro de su propia red Wi-Fi.

## Requisitos

- Android 8.0 o superior recomendado;
- Dispositivo Android de 64 bits;
- Conexión a Internet para descargar los archivos iniciales;
- Espacio libre en el almacenamiento interno;
- Minecraft Bedrock instalado en otro dispositivo o dentro del mismo entorno de red para realizar pruebas.

---

## Cómo usar

1. Instala la aplicación en tu dispositivo Android.
2. Abre PocketHosting.
3. Ejecuta la instalación/actualización de los archivos necesarios.
4. Pulsa **Iniciar** para encender el servidor.
5. Accede a la pestaña **Consola** para seguir los registros en tiempo real.
6. Utiliza el campo de comandos para ejecutar comandos en el servidor.
7. Accede a la pestaña **Archivos** para editar configuraciones, plugins y mundos.
8. Conéctate al servidor utilizando la IP local mostrada por la aplicación y el puerto configurado.

---

## Observaciones

Esta aplicación fue creada para facilitar las pruebas, el estudio y el desarrollo con Altay en Android.

Para servidores públicos con muchos jugadores, uso comercial intensivo o entornos de producción avanzados, se recomienda evaluar un alojamiento dedicado, un VPS o una infraestructura de servidor profesional.
