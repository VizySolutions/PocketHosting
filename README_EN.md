**PocketHosting** is an Android application developed by **Vizy Solutions** to create, manage, and run **Altay** servers directly on a mobile device.

The goal of the app is to allow developers, server owners, and advanced users to test plugins, worlds, and Altay configurations without needing to pay for external hosting or keep a computer running all the time.

---

## About the application

PocketHosting turns an Android device into a testing environment for Minecraft Bedrock servers using Altay.

With it, users can download, start, stop, restart, and manage an Altay server directly from the device through a simple and practical interface.

The application was designed mainly for:

- Altay plugin developers;
- Minecraft Bedrock server owners;
- Users who want to test configurations locally;
- People who do not have paid hosting;
- Study, development, and testing projects.

---

## Main features

- Create and run an Altay server on Android;
- Download the latest Altay version from the official releases;
- Start, stop, and restart the server;
- Real-time console;
- Command field to send commands directly to the server;
- Server status display;
- Local IP address and port display;
- Online player display;
- Altay version display;
- Integrated file manager;
- Server file editing;
- File upload to the server;
- Multi-language system.

---

## What is it for?

PocketHosting is designed to make it easier to create and manage Altay servers on Android devices.

It can be used to test plugins, configure worlds, edit server files, execute console commands, and verify that a server is working correctly before moving the project to professional hosting.

It can also be used as a simple solution for users who want to run a local server on their own Wi-Fi network.

This application is intended for:

## Requirements

- Android 8.0 or higher recommended;
- 64-bit Android device;
- Internet connection to download the initial files;
- Free space on internal storage;
- Minecraft Bedrock installed on another device or within the same network environment for testing.

---

## How to use

1. Install the application on your Android device.
2. Open PocketHosting.
3. Run the installation/update process for the required files.
4. Tap **Start** to launch the server.
5. Open the **Console** tab to follow the logs in real time.
6. Use the command field to execute commands on the server.
7. Open the **Files** tab to edit configurations, plugins, and worlds.
8. Connect to the server using the local IP address displayed by the application and the configured port.

---

## Notes

This application was created to make testing, studying, and development with Altay on Android easier.

For public servers with many players, intensive commercial use, or advanced production environments, consider using dedicated hosting, a VPS, or a professional server infrastructure.
